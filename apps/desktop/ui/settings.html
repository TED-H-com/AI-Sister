    出了事，說得出來

    跑一跑、測一測，然後按這顆鍵：她會把「剛剛到底發生了什麼」寫成一個 文字檔，你可以整份貼給人看。 不會多記任何東西——那些數字本來就在硬碟上（她問 CLI 的每一趟花了幾毫秒、哪一趟慢、哪幾次沒問、上一場錄製量到什麼）， 只是沒有人會去開那些檔案。

    檔案中間有一條線。線以上沒有你螢幕上的內容：那幾格 能放的東西是時間、次數、結局代號、毫秒和版本，放不下別的。線以下是 她最後幾句答案的原文和 log 的尾巴，兩節各自獨立，不想給就整段刪掉 再貼。遮蔽只換得掉認得出來的路徑和名字，那是一份黑名單，不是保證， 所以線以下請你自己看一眼。

    產品與資料條款

    四姊妹與 13 位閨密是受同名 AI 產品啟發的虛構角色；AI-Sister 是獨立產品， 未與這些供應商合作、隸屬或獲其背書。

    大腦登入由你選擇的 Claude Code、Codex、Gemini 或 Grok CLI 自己完成；AI-Sister 不收也不保存該服務的密碼或 token。連線測試只送固定測試句。第二張同意書生效後， 每個文字問題先由該 CLI 決定要查哪些記憶；AI-Sister 在本機代查，再把命中的文字與 出處交回同一支 CLI 作答。不送畫面檔，也不把資料庫檔案交給 CLI。

    Azure 每份新答案只送出該題答案正文原文一次；手動重播會再送一次。正文可能含姓名、 電話與金額，且不先遮罩。不送截圖、來源連結、memory id、整份資料庫、其他文字或角色選擇。 金鑰長期只存於 Windows Credential Manager，不寫入 config.toml、log、資料庫或 export， 也不會回傳顯示。回傳的 MP3 只在記憶體播放。停止朗讀會丟掉晚到的音訊；已開始的請求 最長可執行 45 秒，設定操作會在它結束後生效。Azure Speech 的供應、配額與計費依 Microsoft 與你的 subscription 為準。
